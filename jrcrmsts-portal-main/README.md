# JRCRMSTS Enterprises

Company website for JRCRMSTS Enterprises & Project Management Consultant, showcasing architecture, interiors, structural design, town planning, construction, and project costing services.

## Development

Requires Node.js 22 or later.

```powershell
cd .\jrcrmsts-portal-main
npm install
npm run dev
```

The development server prints the local address when it starts.

## Production build

```powershell
npm run build
```
