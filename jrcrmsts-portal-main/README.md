# JRCRMSTS Enterprises Website

Official company website for **M/s JRCRMSTS Enterprises & Project Management Consultant**, based in Haryana, India.

The site presents the firm's architecture, interiors, structural design, town planning, construction, and project-estimation services; project gallery; client list; and office contact details.

## Technology

- React and TypeScript
- TanStack Start and TanStack Router
- Vite
- Tailwind CSS

## Requirements

- Node.js 22 or later
- npm

## Getting started

Run these commands from the website project directory:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm test` | Run the test suite |

## Project structure

```text
public/       Static public assets
src/assets/   Imported images and media
src/components/ Reusable interface components
src/hooks/    Shared React hooks
src/lib/      Shared utilities
src/routes/  File-based application routes
src/test/     Test setup and test files
```

TanStack's route filenames and generated route tree are intentionally kept in their framework conventions.
